description: We define mathematically the notions of policy, value, action-value, and optimal policy. This formulates concretely the main objective in RL. We then start with model-based RL, where the environment is modeled as a known MDP. We can evaluate a given policy simply using statistical analysis. We derive the Bellman equation for the value and action-value functions. These equations enable us to compute the values or action-values from a set of fixed-point equations without needing to take nested expectations.
